# ひだまりの家 ─ リハビリデイサービス サイト

秋田県大仙市のリハビリデイサービス「ひだまりの家」のコーポレートサイトと、
スタッフ向け業務支援システム「ケアコンパス」（モック）です。

> **コンセプト：「陽だまりのような、あたたかい安心を。」**
> 高齢のご利用者が迷わず読みやすく使え、ご家族が信頼を寄せられるサイト。

## 公開URL（GitHub Pages）

- コーポレートサイト：`https://omega-ai-lab-39.github.io/hidamari-no-ie/`
- スタッフ用ケアコンパス：`https://omega-ai-lab-39.github.io/hidamari-no-ie/staff/`

## 構成

```
/
├─ index.html        … コーポレートサイト（1ページLP）
├─ styles.css        … デザインシステム（CSS変数に集約）
├─ favicon.svg       … サイトアイコン（太陽）
├─ DESIGN.md         … デザイン仕様書
└─ staff/
   ├─ index.html            … 業務支援システム「ケアコンパス」（単一HTML）
   └─ system-architecture.svg … システム構成図
```

## ケアコンパス（業務支援システム）について

- 単一 HTML／依存ライブラリなし。データはブラウザ内（`localStorage`）にのみ保存され、外部送信はありません。
- 機能：ダッシュボード／利用者管理（ケアスコア3層自動振分）／リハビリ記録／
  承認ワークフロー（段階ゲート・役割別権限）／分析レポート。
- 記載の氏名・イラスト・数値はすべてデモ用のイメージです。

## 開発

静的サイトのため、ローカルでは任意の静的サーバーで確認できます。

```bash
# 例：Python
python -m http.server 8000
# → http://localhost:8000/
```
